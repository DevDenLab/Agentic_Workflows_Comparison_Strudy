# Runbook: email and collaboration tools

## Repeated credential prompts in the desktop mail client
Usually a stale cached token rather than an actually-wrong password. Clearing the cached
credentials for the account resolves most cases without an actual password reset.

## Meeting audio or video drops after the first minute
Correlates strongly with Wi-Fi roaming between access points (moving between rooms) more often than
with the collaboration app itself. Ask where the person was sitting and whether they moved.

## Shared mailbox or calendar access requests
A request to be added to a team or shared mailbox is routine self-service once a manager or an
existing delegate approves it. A request for someone's individual mailbox is not the same category;
see the access-and-identity runbook.
