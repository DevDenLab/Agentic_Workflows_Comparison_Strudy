# Runbook: software requests

## New install or upgrade requests
Confirm whether the software needs a paid licence before treating this as a quick install. Licensed
software requests need manager approval on file; unlicensed or free tools generally do not.

## "It used to work, now it doesn't" after an OS or app update
Treat as a compatibility regression, not a fresh install request, even if the user asks for a
reinstall. Reinstalling rarely fixes a genuine post-update regression and wastes a cycle before the
real fix (a known-good version, or a vendor patch) is found.
